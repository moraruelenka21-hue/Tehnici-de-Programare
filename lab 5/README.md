# Funcții, metode și importuri pe web

`main.py` și `webtools.py` conțin aplicația și funcțiile reutilizabile. Fișierele `part*.py` acoperă părțile principale, iar directorul `exercises` conține cele 50 de exerciții individuale.

```sh
python -m pip install -r requirements.txt
python main.py https://cybercor.org
python run_exercises.py 1
python -m unittest test_webtools
```
